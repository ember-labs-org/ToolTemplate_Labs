# Scripts

Put any scripts that fetch or process data here, with a line below on what each one does and how to run it.

If a script needs a login or API key, read it from an environment variable or GitHub secret. Never write it into the script.

Automated collection must follow the datasets section of Ember's AI policy: use APIs designed for automation, never automate a username and password login, never use proxies for government sites, and never get around captchas or geo-restrictions.
